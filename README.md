# ⚡ CiberMind - Cyber Training Platform
## 📺 Demostración del Proyecto
https://github.com/tu-usuario/tu-repo/raw/main/1000353152.mp4


Plataforma interactiva de entrenamiento en ciberseguridad desarrollada para gamificar el aprendizaje de conceptos técnicos.

## 🚀 Funcionalidades Principales
**Módulos de Juego:** Trivia, Emparejamiento de conceptos y Ordenamiento lógico.
**Snake Cyber:** Un juego clásico adaptado para recolectar datos y aprender conceptos de seguridad digital.
**Sistema de Progresión:** Gestión de niveles, puntos (XP), vidas y rachas de estudio.
**Social & Competitivo:** Ranking global de usuarios, sistema de amigos y logros desbloqueables.
**Personalización:** Galería de avatares (colección de gatos) basados en el nivel del usuario.

## 🛠️ Stack Tecnológico
**Backend:** PHP
**Base de Datos:** MySQL (Archivo cibermind.sql incluido)
**Frontend:** HTML5, CSS3 moderno y lógica de juegos en JavaScript.
**Asistencia:** Desarrollo optimizado mediante **Inteligencia Artificial** para la depuración de lógica estructural y diseño de base de datos.

## 📂 Estructura del Proyecto
/avatares.php: Gestión de perfiles visuales.
/ranking.php: Lógica de competencia global.
/snake.php: Juego interactivo de recolección de datos.
cibermind.sql: Estructura completa de la base de datos.
